Ordering Food

Goal: By the end you can get someone's attention politely, ask for a menu, point to an item, and request it.

Mika and Alex are choosing food at a restaurant. The Japanese dialogue below is copied verbatim from the selected story script.

Content status: AI-written learning notes; Japanese and romaji have not been verified by a native speaker.

Dialogue

  • Mika
    すみません！
    Sumimasen!
    Excuse me!
  • Alex
    メニューを おねがいします。
    Menyuu o onegaishimasu.
    The menu, please.
  • Mika
    これを おねがいします。
    Kore o onegaishimasu.
    This one, please.
  • Alex
    ぼくは これを ください。
    Boku wa kore o kudasai.
    I'll have this, please.
  • Mika
    ありがとうございます！
    Arigatou gozaimasu!
    Thank you!

Vocabulary

  • すみませんsumimasenExcuse me / Sorry; polite way to get attention
  • メニューmenyuumenu
  • をoobject particle; marks what is requested or acted on
  • これkorethis / this one (near the speaker)
  • お願いします (おねがいします)onegaishimasuplease / I'd like … (polite request)
  • ぼくbokuI / me; commonly used by boys and men, though usage varies
  • はwatopic particle; written は and pronounced wa as a particle
  • くださいkudasaiplease give me … / please …
  • ありがとうございますarigatou gozaimasuthank you (polite)
  • ありがとうarigatouthank you (more casual; listed in the source vocabulary, not spoken in this dialogue)

Grammar

Noun + を お願いします

This is a polite way to request something: メニューを おねがいします means “The menu, please.” を is written を but pronounced “o” when it is the object particle.

これ = this one

これ can stand alone as “this / this one.” Use これを おねがいします or これを ください while pointing at a menu item. この means “this” before a noun, as in この りょうり (this dish).

お願いします vs ください

Both can be used to request an item. お願いします is a broadly useful polite request; ください means “please give me” or “please do.” Tone and context matter.

ぼくは … — marking the topic

は marks the topic and is pronounced “wa.” In ぼくは これを ください, Alex sets himself as the topic: “As for me, this one, please.” Japanese often omits pronouns when context is clear.
